A program that writes the funniest single-line resignation letter it can: an office worker quits by turning the dreaded phrase "per my last email" back on the job itself — per my last day instead. One line, 95 characters, no padding, ready to send. The judge compares entries two at a time; this one bets everything on a single twist in the last three words.

## Run it

```sh
node main.ts
```

The program writes the entry to `entry.txt` under `$MAKEFUN_OUTPUT_DIR` (default `/output`).
